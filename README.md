# 负产阶级

一款以「债务与经营」为核心的网页模拟游戏：想办法把债还清，并在过程中经营自己的生活。

## 在线试玩

<https://houhuizhang80-wq.github.io/fuchan-jieji/>

## 本地游玩

整个游戏是一个 `index.html`（约 2.1 MB，无外部依赖）：

```
双击 index.html 即可
```

## 玩法要点

- **清债主线**：围绕「清债与经营」推进，完成清债是核心目标。
- **投资与黑市**：通过投资页进行资金运作，黑市有高回报也有风险（「黑市余波」）。
- **目标系统**：目标页会给出阶段性任务，完成后领取奖励。
- **成长元素**：技能点、声望、荣誉入殿、孩子成长线，都会影响后续走向。
- **资源**：余额、手续费、免广告券等，需要精打细算。

## 技术说明

- 纯前端单文件，HTML + 内联 CSS/JS，无构建、无后端。
- 存档在浏览器本地，清缓存会丢档。
